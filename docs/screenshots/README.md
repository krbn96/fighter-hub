# スクリーンショット

このディレクトリには、トップレベルの`README.md`から参照するスクリーンショット画像を配置しています。

## 配置済みファイル

| ファイル名 | 画面 |
|---|---|
| `home.png` | TOPページ |
| `tournament-list.png` | 大会一覧 |
| `team-detail.png` | チーム詳細 |
| `team-applications.png` | チームへの参加申請一覧(Team owner向け) |
| `mypage.png` | マイページ(プロフィール・Discordアカウント連携状況) |
| `admin-tournaments.png` | ADMIN大会管理画面 |

これらは`README.md`の`## Screenshots`セクションに既に組み込まれています。画像を追加・差し替えする場合は、この一覧と`README.md`の両方を更新してください。

## 画像を追加・差し替える際の注意

- メールアドレス等の個人情報が写り込んでいないか必ず確認してから配置してください。
- GitHub上で正しく表示されるよう、`README.md`からの相対パス(`docs/screenshots/<ファイル名>`)で参照してください。
